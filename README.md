# Hobby Class 3D

Interactive 3D model of the Hobby Class at LVL 80.50, Kumarans CBSE Junior Block.

Live: https://sherlyguides.github.io/hobby-class-3d/

- `index.html` — three.js viewer (rotate, pan, zoom, preset views, X-ray, wireframe)
- `model.js` — the model embedded as base64 (built from `c.glb`)
- `c.glb` — the furnished room model (SketchUp export)
- `hobby_class.glb` — the Blender-built version of the same room
